# 賽博易斷 (CyberIChing) 像素占卜與學習系統 V2

> **CyberIChing v2.0** 是一個結合 **8-Bit 復古像素美學**、**CRT 賽博終端機** 與 **《高島易斷》實戰解卦** 的現代易經占卜與知識學習平台。

## 🌟 核心特色

1. **8-Bit CRT 賽博終端機體驗**：
   - 磷光綠 / 霓虹青 / 賽博紫 / 警戒紅像素配色。
   - 掃描線 (Scanlines)、螢幕微光微震 (Phosphor Glow)、自製純 Web Audio 8-bit 復古音效合成器。
   - `steps(6)` 硬派 6 幀 3D 卡牌定格翻牌特效與動爻高頻閃爍紅光。

2. **模組一：賽博占斷與終端機解卦 (Divination Module)**：
   - **起卦法**：支援「三枚銅錢筮法 (逐步投擲 6 爻)」與「一鍵賽博量子起卦」。
   - **朱熹動爻定則**：自動依動爻數（0~6 爻）精準提煉解卦核心焦點與權重。
   - **階層式深度報告**：
     - 本卦與之卦 6 爻像素對比。
     - 周易原文（卦辭、彖傳、象傳）與白話解讀。
     - 《高島易斷》實務斷語與明治維新歷史占例。
     - 現代行動決策指引 (SOP)。

3. **模組二：64 卦像素記憶卡學習系統 (IChing Academy / Flashcards)**：
   - **模式 A：看卦象猜卦名**（繪製 6 爻像素條，四選一測驗 + `steps(6)` 翻牌揭曉）。
   - **模式 B：看卦名憶卦象**（顯示卦名，翻牌複習八卦結構與二進位碼）。
   - **連勝與統計矩陣**：Local Storage 記錄答題數、正確率與最高連勝。
   - **錯題收集本 (Error Notebook)**：自動歸納答錯卦象，支援專項加強重測。

4. **模組三：多管道社群分享與動態像素 QRCode 模組 (Social & QR Sharing)**：
   - **專屬短網址 (Deep Link)**：依卦象 ID 與變爻 Query 自動生成專屬還原網址。
   - **純 JS 像素 QRCode**：離線即時繪製綠黑像素 QRCode，支援點擊下載圖檔。
   - **社群一鍵轉發**：LINE、Facebook、Email 格式化訊息轉發。
   - **ASCII 終端報告複製**：一鍵複製純文字 ASCII 像素卦象與完整報告至剪貼簿。

5. **模組四：64 卦全典檢索資料庫 (Codex Matrix)**：
   - 全覽 64 卦文王序號、二進位碼與上下八卦歸屬。
   - 支援八卦快速過濾與全欄位即時搜尋。
   - 點擊彈出終端詳細視窗。

## 🚀 快速啟動

本系統為純原生現代 Web 應用，**無需任何外部依賴或打包編譯**，可直接於任何現代瀏覽器中開啟使用：

1. 直接以瀏覽器開啟專案資料夾下的 `index.html`：
   ```bash
   # Windows PowerShell
   Start-Process index.html
   ```
2. 或使用任何靜態伺服器（如 Python / Node http-server / VSCode Live Server）：
   ```bash
   npx serve .
   # 或
   python -m http.server 8080
   ```
